走 Toonflow 适配器 512×512 → 2.2s。图像质量正常，无 fp8 劣化。

**下载踩坑（重要）**
1. hf-mirror 长连接被限速到 0.67MB/s；**ModelScope 新建连接可 14MB/s，长连接同样会掉速**。解法：`scripts/dl_parallel.py`（16 线程 × 16MB 分块 × 每块独立短连接），实测稳定 10–14MB/s，17GB 约 19 分钟。
2. **之前 hf-mirror 那个下载任务是 `while` 重试循环**，kill curl 会立刻被拉起。必须 `taskkill //T //F` 杀 bash 父进程树，否则它会往同一文件继续追加（把 17.24GB 写成 17.26GB）。
3. **两个进程写同一文件 + 预分配 truncate = 静默损坏**。第一次 sha256 校验失败（7c451c87 ≠ ead42627），因为 hf-mirror 的续传偏移被我的 truncate 污染，写入了错位数据。**只靠 safetensors 头部校验 + 文件大小是查不出来的**，头部能解析、大小也对，但内容错了。必须整文件 sha256。
4. 结论：**大模型下载禁止多进程并发写同一路径**；校验必须用仓库给的 sha256 全文件比对。
5. ModelScope API 查文件清单+哈希：`https://modelscope.cn/api/v1/models/{repo}/repo/files?Revision=master&Recursive=true`；HF 侧 `https://hf-mirror.com/api/models/{repo}?blobs=true`
