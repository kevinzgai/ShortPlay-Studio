## 六、生成参数与工作流建议

**比例**
- 角色三视图：`3:2` 横版（九宫格式并排）
- 角色单独立绘：`3:4` 竖版
- 场景概念图：`16:9`；核心场景 S04 / S05 另出 `2.35:1`

**通用负面词（Negative）**
```
模糊，低清晰度，多余的手指，畸形的四肢，现代感强的插画风，3D渲染，动漫感，塑料皮肤，过度磨皮，脸部对称过度，英文字幕，水印，logo，鲜艳高饱和，暖色调
```

**推荐生成顺序**
1. 先生成 **C01 水雷** 三视图 → 定下全片的皮肤质感基准（青灰白 + 真实毛孔）
2. 用 C01 的风格去生成 **C03 爷爷 / C04 胖老头 / C05 奶奶**，保证"惨白脸"是同一套调子
3. 生成 **C02 鬼媳妇**，重点打磨衣料反光与流苏，这个资产后期出场最多
4. 全部角色 → 转彩铅线稿存档
5. 生成场景 **S04 鬼宴长街 → S05 荒坟土坡 → S01 堂屋**（这三场撑起第一章 80% 的画面）
6. 补齐玩伴 C06-C08 与群演 C09

**一致性提醒**
- AI 生成的人脸极易雷同：本章有 4 个男性角色（水雷/胖老头/二狗/小强），务必靠"脸型 + 瑕疵 + 服装"三者同时差异化，不要只靠年龄
- 每次换镜头重生成时，把第二节的"固定关键词串"原样粘回去，不要重写
- 鬼角色的"惨白"必须是**同一种惨白**，否则后期剪辑会像两个世界的鬼
