出图工作区 · 4 个「去 AI 味」方向

同一块内容（模型设置侧栏 + 资产卡片 + 底部出图操作），四种视觉语言。以下「AI 味」元素在四个版本中全部移除，请对比整体气质后挑一个：

  • 紫色糊满全局 → 收敛为单一主色，只给主按钮和选中态
  • 渐变 / 光晕 / 发光点 → 纯色、细边框、无 shadow 彩晕
  • ✦ 花哨符号 → 按钮只说人话
  • 药丸徽章满天飞 → 方角小标签或纯文字
  • 满屏圆角胶囊 → 控制圆角统一、克制

V1 · 克制灰阶

Linear / Notion 气质 · 最不像 AI

黑白灰打底，黑色就是主色：唯一的强调色给了「生成」按钮。选中态是浅灰底而不是紫色填充。信息密度高、视觉最安静，和分镜工作台的 Linear 风格最连贯。

V2 · 暖纸工作室

暖调纸感 · 有「剧组」的手作气质

米白纸底 + 墨色文字，标题用衬线字体，像美术组的工作手册而不是 SaaS 后台。选中年态是淡驼色填充，操作底栏带一层浅纸色。适合想和「电影 / 短剧」行业气质绑定的话。

V3 · 瑞士网格

黑白硬边 · 专业工具感最强

接近印刷排版的硬边网格：1px 黑边、近方角、mono 大写小标签、硬阴影。选中态直接反白（黑底白字），对比最强烈。看起来「贵」但改动幅度最大，全站要跟着统一。

关于原子化 CSS：这页 demo 全部用 utility class（.row .g8 .t12 .fw6…）+ 版本级 CSS 变量写成，四个版本共用一套骨架、只换变量——这就是原子化的好处。正式迁移建议 UnoCSS（Vite + Vue 生态首选，按需生成、零运行时）：先用 presets-uno（Tailwind 语法）在新改的组件上试水，老样式文件按「改到哪个组件就迁哪个」的节奏渐进替换，不搞一次性重写。挑好版本告诉我，我把选中的方向落回 AssetPanel.vue 真实组件。
